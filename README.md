# Wedding Website Demo

An editorial wedding invitation experience in ivory, sage and soft gold.

## Preview
Open `index.html` in a modern browser. No build step or dependencies.

## Personalise before delivery
Replace the sample names, date, venue, ceremony/reception details, dress code, RSVP email and all placeholder copy. Confirm every detail with the couple before publishing.

## Included
- Responsive editorial wedding landing page
- Ceremony, reception and dress-code cards
- Couple's note and email RSVP link
- Netlify-ready static configuration

All names, dates and venues are fictional sample content.
